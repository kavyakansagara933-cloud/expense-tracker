# Expense Tracker

A Python command-line application for tracking income and expenses. The application allows users to manage transactions, view financial summaries, filter transactions by category, and store data permanently using JSON.

## Features

- Add income
- Add expenses
- View all transactions
- Calculate total income
- Calculate total expenses
- Calculate remaining balance
- Filter transactions by category
- Partial category search
- Case-insensitive category search
- Delete transactions
- Input validation
- JSON persistent storage
- Automated testing with pytest

## Technologies Used

- Python
- JSON
- pytest
- Git
- GitHub
